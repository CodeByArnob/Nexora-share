## 🌟 What's New in v1.1.0

### 1. APK Size Optimization & ABI Splitting
- **>62% File Size Reduction**: Implemented `--split-per-abi` Android packaging, shrinking the modern phone target (`arm64-v8a`) down to **25.0 MB** and legacy 32-bit (`armeabi-v7a`) down to **20.9 MB**.
- **R8 Minification & Resource Shrinking**: Enabled `isMinifyEnabled = true` and `isShrinkResources = true` with targeted ProGuard rules (`-keep class io.github.codebyarnob.nexora.** { *; }`) preserving FFI, SQLite, and ML Kit models.
- **Font Tree-Shaking**: Stripped 99.3% of unused Material icon glyphs, reducing font assets from 1.64 MB to 11.7 KB.
- **Pure Android Native SQLite**: Native `libsqliteX.so` removed in favor of Android framework OS SQLite, saving 1.2 MB per ABI.

### 2. Large File Transfer Initiation Latency Redesign
- **Lightweight Manifest Negotiation**: Senders transmit an immediate, lightweight `TransferOffer` containing only metadata (session ID, file count, sizes, MIME types, parameters) upon TCP connection.
- **Sub-Second Confirmation Popup**: Receivers validate permissions and display the incoming transfer prompt within **18–31 ms** for 2 GB+ files (well under the 1,000 ms SLA).
- **Streaming On-the-Fly SHA-256**: Pre-transfer whole-file hashing eliminated; files are hashed in parallel with network streaming chunks with constant 512 KB RAM and zero post-transfer verification lag.

### 3. Production Transfer Completion Protocol
- **Reliable Two-Way Completion Handshake**: Replaced unilateral stream closing with an explicit `TransferComplete` ↔ `TransferCompleteAck` wire handshake.
- **Immediate Live-Transfer Demotion**: Senders and receivers instantly transition state from `transferring` to `completed`, stop real-time speed counters, dismiss active Cancel/Pause buttons, and persist verified metrics into SQLite transfer history.

### 4. Native Camera QR Code Scanner
- **Google ML Kit Integration**: Deployed native CameraX barcode scanning engine with 60 FPS viewport processing and sub-100ms QR decode latency.
- **Full-Screen Scanning Interface**: Branded cyber-frame overlay, animated neon laser sweep, hardware torch flashlight toggle, gallery QR image picker, and manual IP fallback.

### 5. 6-State Device Discovery Engine
- **Complete Discovery State Machine**: Initial, Scanning, Devices Found, No Devices Found, Permission Required, and Error states.
- **Safe Cryptographic Fingerprint Verification**: Mathematical truncation safety prevents `RangeError` on peer devices.
