## 🌟 Overview

NEXORA v1.0.0 represents the first official production release of the NEXORA peer-to-peer file sharing platform. Engineered with a senior architectural foundation, NEXORA enables instant, secure, and completely private file transfers between devices over local Wi-Fi or mobile hotspots with zero cloud dependency.

---

## 🚀 Key Features in v1.0.0

- **Zero-Cloud P2P Architecture**: Direct socket transmission between devices with zero cloud servers, zero trackers, and zero telemetry.
- **Sub-Second Initiation**: Immediate `TransferOffer` manifest negotiation (< 5 ms) and prompt SLA (< 20 ms).
- **Bounded-Memory Streaming**: Handles massive multi-gigabyte files within a fixed 1 MB RAM buffer with flow-control backpressure.
- **Native Android Foreground Service**: Background streaming continuity via `FOREGROUND_SERVICE_DATA_SYNC` and persistent notification channel.
- **Streaming SHA-256 Verification**: On-the-fly chunk digestion during active transmission with 0.00 ms post-transfer lag.
- **Ed25519 Identity**: Locally generated cryptographic keypairs with SHA-256 public key fingerprinting.

## 📱 Compatibility & Requirements

- **Supported Platforms**: Android (Mobile)
- **Minimum Android Version**: Android 8.0 Oreo (API level 26) or higher
- **Target Android Version**: Android 15 (API level 35)
- **Supported ABIs**: `arm64-v8a`, `armeabi-v7a`, `x86_64`
- **Network**: Wi-Fi, Local LAN, or Mobile Hotspot (No Internet or cloud access required)
- **Required Permissions**: `NEARBY_WIFI_DEVICES`, `FOREGROUND_SERVICE_DATA_SYNC`, `POST_NOTIFICATIONS`, `CAMERA`, `WAKE_LOCK`

## 🔒 Security Summary

- All transfers operate strictly within local network boundaries (`224.0.0.167:48843` for discovery, `48842` for TCP streaming).
- Relative paths are sanitized through `PathSanitizer` to prevent directory traversal attacks.
- Ephemeral pairing supported via optical QR codes and 6-digit SAS codes.
