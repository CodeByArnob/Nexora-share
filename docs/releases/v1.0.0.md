## 🌟 What's New in v1.0.0

### 📡 Root-Level Peer Discovery & Device Identity
- **Resolved Android-to-Android Peer Discovery**: Replaced hardcoded device IDs with persistent cryptographic UUIDs and unique device identities stored in SQLite. Multiple phones on the same network now reliably discover each other without dropping packets.
- **Hardware Model Detection**: Integrated dynamic device identification via `device_info_plus`. Devices accurately broadcast their genuine hardware name (e.g., Realme, Samsung Galaxy, Google Pixel, Xiaomi) instead of generic mock placeholders.
- **Native Android MulticastLock**: Acquired `WifiManager.createMulticastLock()` and high-performance `WifiLock` in `MainActivity.kt`, preventing Android power-saving chipsets and kernels from dropping UDP multicast and broadcast packets.
- **Subnet-Directed Multi-Target Broadcast**: Broadcasts presence across all local IPv4 subnet broadcast addresses (`192.168.x.255`), global broadcast (`255.255.255.255`), and UDP multicast (`224.0.0.167:48843`).
- **Instant Bi-Directional Discovery**: Immediate unicast announcement responses upon receiving peer broadcasts, slashing discovery latency to under 100ms.
- **Direct IP & QR Pairing Fallback**: Seamlessly bypasses router AP Isolation / Client Isolation with a dedicated "Connect by IP" dialog and real-time IP display on the home screen.

### ⚡ Large File Transfer & Performance
- **Bounded-Memory Streaming**: Fixed 1MB buffer chunk slicing with flow-control backpressure transfers 5GB, 10GB+ files smoothly without inflating RAM or causing Out-Of-Memory (OOM) crashes.
- **Android Foreground Service (`dataSync`)**: Transfer continues uninterrupted when the user navigates away, locks their screen, or switches apps, compliant with Android 14+ background execution policies.
- **Verified Resumption**: Interrupted transfers automatically resume from the last verified chunk checkpoint using SQLite tracking.

### 🎨 Premium UI & Motion Polish
- **Branded Design System**: Midnight Navy (`#14243B`), Electric Blue (`#3978F6`), Signal Teal (`#39C6B0`), and Dark Surface (`#17243A`).
- **GPU-Accelerated Motion**: Discovery pulse radar, live animated progress indicators with transfer speed metrics, and accessible reduced-motion support.
